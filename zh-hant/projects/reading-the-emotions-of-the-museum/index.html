閱讀博物館的情感：M+ 展品說明文字的情感與詞頻分析

把 M+ 博物館五十八張展籤當成一份語料來讀。這間博物館用的語氣是「歡迎」，不是「教導」：數字也這樣說。

  • 輕微正面 1
  • 中立 1

五十八張繁體中文展籤，先由百度 NLP 情感分析 API 逐張評分（0–1)，再分成五個等級。

兩個問題

  1. 01

    M+ 博物館的展籤裡，存在哪些情緒語氣（正面、中立，還是負面）?

  2. 02

    詞頻規律與用詞選擇，反映了博物館怎樣的主題重心與溝通姿態？

  • 作品

  • 設計

項目簡介

在數碼時代，博物館正經歷重大轉變，由以知識為主導的機構，逐步走向以體驗為核心的空間。在這個不斷演變的模式下，訪客的情感與詮釋體驗日益受到重視，而展品說明牌正是塑造訪客觀感的重要中介。說明牌不只是在描述展品，更是影響訪客情感投入的溝通工具。

儘管出現這種轉變，現時關於博物館文本的學術研究多集中於翻譯準確度、可讀性或多元模態特徵，語言表達中的情感面向卻較少受到關注。為回應這個研究缺口，本項目「閱讀博物館的情感：展品說明的情感與詞頻分析」運用數碼人文方法，探究繁體中文展品說明牌所蘊含的情感表達。透過檢視博物館如何運用語言傳達情感、塑造溝通，本研究期望為策展實務及公眾參與策略提供參考。

本研究以位於香港西九文化區的 M+ 博物館為個案。M+ 以視覺藝術、設計、建築及流動影像為重點，是一所面向全球的機構，體現二十及二十一世紀的文化表達。其規模、地位、政府支持，以及對繁體中文語言表達的重視，使其成為探究展品說明如何傳達情感與意義的理想場地。本研究聚焦以下兩項研究問題：

  1. M+ 博物館的展品說明牌呈現哪些情感色調——正面、中性還是負面？
  2. 詞頻模式與詞彙選擇揭示了博物館怎樣的主題優先次序與溝通取向？

數據驅動的研究方法

為回應上述問題，研究採用嚴謹且以數據為本的方法。研究團隊從 M+ 博物館收集了 58 則繁體中文展品說明，並運用三項數碼工具進行分析。

  • 第一，使用 Python IDLE 進行量化詞頻分析，以識別重複出現的詞彙模式，以及描述性或情感性的詞語。
  • 第二，運用 Ctext 製作文字雲，以視覺方式突顯高頻詞，並揭示展品文本中的重要主題與主導概念。
  • 第三，透過 Python Spyder 使用百度 NLP 情感分析 API 進行情感分析。

每則展品說明均獲分配 0 至 1.0 的情感概率分數，其後歸入五個等級：非常負面、中度負面、中性、中度正面及非常正面。此步驟有助系統地劃分情感色調，並更細緻地理解博物館溝通的情感面貌。

主要發現：詞彙模式與主題

對 M+ 博物館展品說明牌的分析，揭示了該館主題重點的鮮明模式。透過詞頻分析及文字雲視覺化，多個詞語明顯居於主導地位：「作品」、「藝術」、「設計」、「建築」、「社會」及「文化」。

這些高頻詞反映 M+ 博物館對創意、文化表達及社會脈絡的高度重視。此外，「我們」和「生活」等詞語的突出位置，突顯出以人為本、強調集體的色彩。這顯示博物館有意邀請訪客與展品建立情感連結，而非停留於枯燥的學術描述。

M+ 博物館內的展品說明牌

情感分析結果

情感分析清晰呈現了博物館文本的情感傾向。與外界對博物館語言中性、客觀的傳統期望相反，M+ 的說明牌顯示出明顯的正面偏向。

  • 非常正面：49 則（84.5%）
  • 非常負面：5 則（8.6%）
  • 中性：1 則（1.7%）
  • 中度正面：1 則（1.7%）

數據顯示近 85% 的說明牌屬於「非常正面」類別。正面情感一般透過表達欣賞與鼓勵的詞語傳達；至於少數負面說明牌，則多與歷史掙扎或社會衝突有關。整體而言，館方語言包容且具情感感染力，而非嚴格客觀。

結論

本研究展示數碼人文在揭示博物館溝通「情感面貌」方面的價值。結果顯示 M+ 博物館重視以訪客體驗為本的路向。透過理解詞彙選擇與情感如何影響參與，策展人可設計更具情感感染力的文本。最終，這些以數據為基礎的分析，能有效闡明語言表達，並加強博物館與訪客之間的文化及情感連繫。
